# Gmail Support Agent | n8n + OpenAI

An AI-powered email support automation workflow built using **n8n, OpenAI, Gmail, and Google Sheets**.

## Overview

This project automates first-level customer support by processing incoming Gmail messages, retrieving answers from an FAQ knowledge base, and generating email drafts for human review.

## Key Features

- **Email Monitoring:** Detects incoming customer emails using Gmail Trigger.
- **AI-Powered Responses:** Understands queries and generates replies using OpenAI.
- **Knowledge Retrieval:** Fetches approved answers from Google Sheets.
- **Conversation Memory:** Maintains context using Simple Memory.
- **Automated Drafts:** Creates Gmail drafts without sending emails automatically.
